# Start Here

The metric is output per dollar of tokens, not the bill. Cutting spend on a feature that drives revenue is as bad as paying flagship prices for a task a 25x-cheaper model handles.

The order:

1. [Must-dos](01-must-dos.md) — gateway, caps, tags, a golden eval set. Visibility before optimization.
2. [Low-hanging fruit](02-low-hanging-fruit.md) — caching, batch, downshifting, trimming. Days of work.
3. [Big levers](03-big-levers.md) — routing, self-hosting, distillation, commitments. Weeks of work; each has a break-even line.
4. [Culture](04-culture.md) — what keeps fixes from regressing.
5. [Audit checklist](05-audit-checklist.md) — 15 questions, run quarterly.

Two rules that outlast any price table:

- The cheapest token is the one you never send. Caching, trimming, and dedup apply before any model choice.
- Gates beat alerts. The published runaway-bill postmortems all had dashboards; none had a budget gate.
